# HCSEASYMATH (in-tree, pre-alpha)

A local mathematical workbench. **Today it does one thing**: an exact symbolic derivative of a
validated expression, through a loopback-only API and a one-page UI. Everything else in
`docs/superpowers/plans/2026-11-08-hcseasymath-plan.md` is planned, not built.

Made with love by hcsmedia. Part of HSCL1 (GPL-3.0-or-later); see `docs/integrations/HCSEASYMATH.md`.

## What is guaranteed (each point has a test)

- User text is **never** passed to `eval`, `exec`, `sympify` or `parse_expr`. An allow-list parser
  (`core/expression_ast.py`) builds the expression; a hostile-input corpus and a fuzzer check it.
- Huge numeric powers are refused **before** they are computed (`9**9**9`, `(10**10000)**10000`).
- Every operation runs in a separate worker process with a wall-clock limit, a memory cap, a
  minimal environment and a capped output size (`jobs/worker.py`). Linux only.
- The API binds `127.0.0.1`, has no CORS, validates `Host` and `Origin`, requires a per-launch
  bearer token for operations, limits body size and concurrency, and hides its schema/docs.
- After exit no listener remains. There is no service and no autostart.
- A failure is a typed result (`invalid_input`, `resource_limit`, ...) and never carries a result expression.

## What it does not do

No integration, no plotting, no ODEs, no accelerators (HCSUDA is `not_used`), no Windows worker,
no packaging. A warm worker is not implemented: one request costs about 0.57 s because each one starts
a fresh Python and imports SymPy (measured, median of 7, repo on a USB drive, WSL Ubuntu 26.04).

## Run (Python 3.14, Linux)

```bash
python3 -m venv .venv
.venv/bin/pip install --require-hashes --only-binary=:all: -r requirements.lock
PYTHONPATH=backend .venv/bin/python -m hcseasymath doctor --json
PYTHONPATH=backend .venv/bin/python -m hcseasymath serve      # prints {"url": ..., "token": ...}
```

Open the printed URL and append `#token=<token>` (the fragment is never sent to the server and is
removed from the address bar). Operations from scripts send `Authorization: Bearer <token>`.

## Test

```bash
.venv/bin/pip install --require-hashes --only-binary=:all: -r requirements-test.lock
.venv/bin/python -m pytest -o addopts= -q
```

From the repository root, `python scripts/forge.py check` runs this gate under WSL when files in
`apps/hcseasymath/` changed (`scripts/hcseasymath_gate.sh`).

## Locks

`requirements.lock` and `requirements-test.lock` are generated by `tools/make_lock.py` from pip's
resolver report for cp314 manylinux wheels; they contain only hashed wheels. Regenerate with
`python tools/make_lock.py runtime > requirements.lock` (and `test`).
