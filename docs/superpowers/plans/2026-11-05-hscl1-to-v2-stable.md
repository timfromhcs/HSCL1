**Goal:** Take HSCL1 from the current Phase‑2 PoC (remastered Kubuntu 26.04.1 ISO that boots to a live Plasma desktop, not yet branded) to a **hardened, VM‑verified, visually QA'd v2.0.0 stable** with original branding, a redesigned HCS Hybrid Desktop, a keyboard‑first control surface, a trilingual handbook and a curated tool catalog.

**Architecture:** Keep the scripted remaster of the official Kubuntu ISO (signed boot chain preserved). All HSCL1 behaviour ships as `.deb` packages built from `packages/` (`hscl-base`, `hscl-branding`, `hscl-desktop`, `hscl-control-center`, `hscl-handbook`, `hscl-security`). The Rust `hscl` CLI (JSON output) is the single backend contract; Qt6/QML Control Center, KRunner command palette and Welcome app call it. Every milestone ends with a VM boot + screenshot gate driven by `scripts/qemu_boot_test.py`.

**Tech Stack:** Bash/Python build scripts, Rust (clap, serde), Qt 6 / QML, Plasma 6.6 look‑and‑feel + KWin scripts, Calamares, QEMU/OVMF (+ swtpm), mdBook (handbook), Astro (website, Vercel), Podman.

**Spec:** `AGENTS.md` (product contract; overrides this plan on conflict) + user request of 2026‑11‑05: "bis v2 stable, hardened, visual QA, eigene Logos, besser UI/UX/Steuerung, mehr Handbook und Tools".

## Global Constraints

- Product name always `HSCL1`; credit `Made with love by hcsmedia`; publisher HCSMEDIA.
- Base: Ubuntu 26.04 LTS `resolute` / Kubuntu 26.04.1, Plasma 6.6, amd64 only; no Kali/Debian/PPA repos on host.
- Languages: `en`, `de`, `fr` for every user‑visible string, handbook included.
- No fake completion, no mock screens, no fabricated screenshots/URLs/hashes; limitations stay public.
- Destructive tests only on disposable qcow2 disks; never force‑push; never commit secrets, VM disks, ISOs.
- All Apple/Microsoft/Omarchy/Kali/Tails branding and assets are off‑limits; logos/icons/wallpapers are original (generated by checked‑in scripts).
- Max 3 fix‑and‑retest loops per gate, then document the blocker (AGENTS.md §15.2).
- **Version decision (user‑directed):** the first stable release is `v2.0.0`; all AGENTS.md v1.0.0 gates (§14.2/§20) plus the v2 additions below must pass. If a critical gate fails, publish `v2.0.0-rc.N`, never a false stable.
- Publishing (GitHub repo creation, Vercel prod, signing) requires owner decisions on repo visibility, licence and signing key; everything else proceeds locally.

## Review Focus

- German/French strings 30–40 % longer than English clip buttons in dock/Control Center → visual QA must run all three languages at 1366×768.
- Theme/branding patch silently not applied (exactly what happened to the wallpaper) → every branding task has an in‑image assertion, not only a build‑time sed.
- Plasma applet config differs between live session and installed target → test both.
- Light theme contrast and reduced‑motion regress after dark‑mode work → token contrast validator runs for all 4 themes.
- Control Center shows static values → each page has a test comparing it with the `hscl … --json` output.
