## 2026-11-07 - B1 follow-up: runtime install and removal (`hscl-cqhecs`)

- Tests (red first, 13 now pass): hash-pin format, no foreign index/editable/VCS lines, size shown before action, exact pip flags via a stub interpreter, wrong Python refused, uninstall keeps user data.
