# Claims and their evidence (reconciled 2026-11-08)

Rule: nothing is stated as working without evidence. "unit-tested" means only the code logic ran in tests; it is **not** a claim that the feature works on real hardware or in the image.

Source snapshot for this reconciliation: `d9a6f02` (`codex/autonomous-wave1`). The local `0.1.3-alpha.0` release set instead records image commit `a55e02320f23b0cb74a06d6215688aafb1557690`, built 2026-11-07, ISO SHA-256 `fc81ad1d93efeac61904879e9def34e39cdceb982bf7aafc070b34afdd4d1ebb`. Source changes after that commit have not thereby been tested in an image. Rows describing older builds below are retained as historical evidence; later measurements supersede their open items only for the named build. See [release readiness audit](research/2026-11-08-release-readiness-audit.md).

Current source corrections (2026-11-08): HCSEASYMATH has six API/CLI operations and all six are exposed by the one-page UI at `d9a6f02`; `plot` returns sampled data rendered as SVG, not a verified mathematical plot image. The recorded app gate is 244 passed (`artifacts/forge/20261108-134544/summary.json`); it is not a browser accessibility or OS-image test. The older five-operation row below is the intermediate 202-test snapshot. `hscl lab` has a tested spec generator; a restricted rootless run and basic-toolset installation now have builder-only evidence in [the lab probe](research/2026-11-08-security-lab-builder-probe.md). CLI execution and HSCL1 guest integration remain absent, and Podman is not in the existing image.
