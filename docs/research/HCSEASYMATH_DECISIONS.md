# HCSEASYMATH decisions

Each decision names its evidence (`HCSEASYMATH_RESEARCH_LEDGER.md`) and the test that will prove it.
Status vocabulary as in the root `AGENTS.md`.

| ID | Decision | Why | Proof (planned test) | Status |
|---|---|---|---|---|
| D1 | The portable app lives in `apps/hcseasymath/`; OS pieces stay in `cli/`, `apps/control-center/`, `packages/debian/`, `distro/`. Not in `hcsuda/`. | Contract 0.2; keeps later extraction cheap. | Directory-boundary test: nothing under `apps/hcseasymath/` imports from outside it. | PLANNED |
| D2 | Target **Python 3.14** (Ubuntu 26.04 system interpreter). The lock holds hash-pinned **cp314 manylinux wheels only**; install uses `--require-hashes --only-binary=:all:`. Gates run in WSL Ubuntu 26.04.1 (Python 3.14.4), not on the Windows 3.13 host. | Ledger R1 (Python version) and R2 (34 packages resolve as wheels). Resolve command: `pip install --dry-run --only-binary=:all: --python-version 3.14 --implementation cp --abi cp314 --platform manylinux_2_28_x86_64 --platform manylinux2014_x86_64 --platform manylinux_2_17_x86_64 --target T sympy numpy scipy fastapi "uvicorn[standard]" pydantic hypothesis pytest httpx` | `pip install --require-hashes --only-binary=:all:` succeeds in a fresh 3.14 venv in WSL and `pip check` is clean. | PLANNED |
| D3 | **No Python MCP SDK.** MCP exposure goes through the existing Rust `hscl mcp` allow-list, calling `hscl math ...`, which calls the app. | Contract 2.2 forbids a second MCP server; the Python SDK just moved to a 2.x major and had CVE-2025-66416 below 1.23.0. If a Python MCP is ever unavoidable: `mcp>=1.23`, stdio only. | Existing MCP tests extended: every `hcseasymath_*` tool is typed, listed in the allow-list, and a shell-shaped argument is rejected. | PLANNED |
| D4 | **Own AST parser, no `sympify`/`parse_expr` on user text.** `ast.parse(mode="eval")` then an allow-list visitor that builds SymPy objects with explicit constructors. No names from globals, no attribute access, no calls except an allow-listed function table, caps on node count, depth and integer-literal digits. | SymPy documents `eval` in `parse_expr` and says to avoid string input (R1). | Corpus of hostile inputs (`__import__`, attribute chains, `lambda`, comprehensions, huge literals, `9**9**9`) all return `invalid_input` or `resource_limit`, never execute; fuzz with Hypothesis. | PLANNED |
| D5 | **Every operation runs in a worker subprocess** with a wall-clock timeout and a memory cap (`RLIMIT_AS` on Linux); the API process only schedules and reports. | A CAS call can run unbounded; a thread cannot be killed safely. Mitigation is general practice, not an upstream-documented SymPy feature (R3). | A test proves a non-terminating simplify is killed within the limit and the API stays responsive. | PLANNED |
| D6 | Local HTTP API: bind `127.0.0.1` only, serve the bundled frontend from the same origin, **validate the `Host` header and `Origin`**, per-launch random token, no wildcard CORS, no autostart. | MCP security guidance names DNS rebinding for any local HTTP server (R1). The token is my design choice, not a spec requirement. | Requests with a foreign `Host`/`Origin` or a missing token get 4xx; port scan shows no listener after exit. | PLANNED |
| D7 | Frontend: React 19.3.1, Vite 8.3.6, MathLive 0.111.4, KaTeX 0.19.1 (all MIT, bundled, no CDN). Three.js 0.187.0 only for an optional 3D view; **2D plots are the default** because the VM likely falls back to software WebGL2 (not measured). | R2 pins; R1 WebGPU note. | `npm ci` reproducible; build output has no external URLs; axe-core passes. | PLANNED |
| D8 | Macaulay2 and Lean are optional, user-installed adapters. M2 from Ubuntu `macaulay2` (1.25.11 in resolute), version recorded in every result. Nothing is added to the ISO. | R2. | Adapter returns `engine_unavailable` when absent; no network call at import time. | PLANNED |
| D9 | Microprice lab labels the size-weighted mid as a **weighted-mid proxy**. The Stoikov estimator is implemented only after the paper's estimator section is read in full. | R3 confirms the distinction; implementation detail unread. | Result schema carries `estimator: "weighted_mid_proxy"`; a test fails if the string "micro-price" appears for the proxy. | PLANNED |
| D10 | The three untracked `AGENTS_*.md` owner files stay untracked until the owner decides. Plans reference them by name. | Root `AGENTS.md` ownership. | `git status` shows them untracked. | IN FORCE |
| D11 | Optional **Lean 4 / mathlib worker** behind a separate tool boundary, never inside the API process. Pin the Lean toolchain and the mathlib commit. Store statement, import context, proof term, Lean output and source hash. Lean kernel acceptance is proof evidence only for that exact statement and environment. A numerical conjecture is never called proved because a model wrote Lean-looking text. No unrestricted code from formula input. | Unified Master 14.1; Goedel-Prover-V2 reports are benchmark specific (`AGENT_AND_FORMAL_RESEARCH_LEDGER.md`). | Adapter returns `engine_unavailable` when absent; a deliberately invalid theorem is refused by the kernel in the adapter test. | PLANNED |
| D12 | Optional **rigorous numerics** adapter (FLINT/Arb ball arithmetic; LeanCert-style certificates later) for small tasks such as root isolation and enclosures. A residual or a finite-difference check is never presented as an error bound; results say whether they are exact, enclosed or merely numerical. | Unified Master 14.2 and 9.6. Sources not yet read (ledger). | Enclosure contains the true value on known polynomials; numeric-only results keep the `numeric` label. | PLANNED |
