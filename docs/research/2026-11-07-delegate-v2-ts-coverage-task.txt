Implement scripts/ts_coverage.py so that tests/unit/test_ts_coverage.py passes (read the test file first for the exact behaviour). Python standard library only (sys.argv, xml.etree.ElementTree, pathlib). Usage: python scripts/ts_coverage.py FILE.ts [FILE.ts ...]. For each file parse the Qt linguist .ts XML: the root TS element has a language attribute (e.g. de, fr, en); for every <message> under every <context> read <source> and <translation>. A message is a problem if its translation element has type 'unfinished', 'vanished' or 'obsolete', or its text is empty or whitespace, or (only when the file language is not 'en' and does not start with 'en_') its text equals the source text exactly (report that as 'identical to source'). Print one summary line per file in the form '<name>: <lang> <finished>/<total> finished' where finished counts messages without a problem, and then one line per problem naming the problem kind ('unfinished', 'empty', 'identical to source') and the source text. Exit code 0 if no file has a problem, 1 if any file has a problem, 2 if a file does not exist or cannot be parsed or no file argument is given (print the reason to stderr). Keep the code small and readable, with a main() function and the usual if __name__ == '__main__' guard.
