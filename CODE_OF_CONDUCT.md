# Code of conduct

We want HSCL1 to be a place where people can build, test and learn without being worn down.

- Be respectful. Disagree with ideas, not with people.
- Be honest and precise, especially about what has and has not been verified.
- No harassment, discrimination, doxxing or personal attacks.
- Security research is welcome when it follows `SECURITY.md`; attacking other people's systems is not.
- Help newcomers; assume good faith; keep feedback specific and kind.

Maintainers may remove comments, commits or contributors that break these rules. Report problems through a private GitHub
security advisory or by contacting the repository owner.
