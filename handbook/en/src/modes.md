# The three modes

| Mode | Purpose | Status |
|---|---|---|
| Workstation | everyday desktop | pre-alpha |
| Security Lab | authorised security testing in isolated containers or VMs | planned |
| Privacy | privacy-oriented workflows | planned |

**Security Lab** will run Kali tools in rootless containers, never by adding Kali repositories to the host. Use it only on systems you are authorised to test.

**Privacy** is not Tails. For situations where your safety depends on strong anonymity, use the genuine Tails release from tails.net.
