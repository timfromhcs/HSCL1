# Introduction

**HSCL1** stands for **Hypercharged Supreme Computing Layout 1**.

HSCL1 is a Linux workstation built on **Ubuntu 26.04 LTS** and **KDE Plasma**. It is published by HCSMEDIA.
*Made with love by hcsmedia.*

> **Status: pre-alpha (`0.1.6-alpha.0`).** HSCL1 boots in virtual machines (UEFI and BIOS) and starts its own
> branded installer (`HSCL1 Installer`, Calamares). Nothing has been tested on physical hardware, and the
> releases are unsigned (SHA-256 checksums only). See [Known limitations](limitations.md).

HSCL1 is **not** Tails, **not** an official Kali release and is not endorsed by Canonical, Offensive Security or the Tails project.
