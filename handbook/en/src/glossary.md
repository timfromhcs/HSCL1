# Glossary

**AppArmor** - Linux mandatory access control that confines programs.

**Calamares** - the graphical installer used by Kubuntu and HSCL1.

**LUKS2** - Linux disk encryption format.

**OVMF / edk2** - UEFI firmware for virtual machines.

**Rootless container** - a container started without administrator rights.

**Secure Boot** - firmware feature that only starts signed boot software.
