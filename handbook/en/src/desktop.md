# Desktop basics

HSCL1 features the HCS Hybrid Desktop built on KDE Plasma 6 with keyboard-driven productivity defaults.

- The floating dock sits centered at the bottom of the screen.
- The slim top bar hosts the application launcher, global menu, clock, and system tray.
- The default wallpaper is **HSCL1 Midnight**. See [Themes](themes.md) to change the look.

## Keyboard shortcuts

HSCL1 uses `Meta` (Super / Windows key) as the primary modifier:

| Shortcut | Action |
|---|---|
| `Meta` | Open Start / Applications menu |
| `Meta + Space` | Focus launcher search (KRunner) |
| `Meta + Enter` | Open terminal (Konsole) |
| `Ctrl + Alt + T` | Open terminal (classic Linux fallback) |
| `Meta + E` | Open file manager (Dolphin) |
| `Meta + D` | Show desktop |
| `Meta + Tab` | Switch applications |
| `Meta + K` | Open shortcut reference |
| `Meta + ,` | Open HSCL1 Control Center |
| `Meta + L` | Lock screen |
| `Meta + Shift + S` | Rectangular region screenshot |
| `Meta + Left / Right` | Snap window left / right |
| `Meta + Up` | Maximize window |
| `Meta + Down` | Minimize / restore window |
| `Meta + 1..9` | Switch to virtual desktop 1 to 9 |
