# Desktop basics

HSCL1 uses the KDE Plasma desktop. Until the HCS Hybrid Desktop layout ships, the standard Plasma behaviour applies:

- The launcher is at the bottom left; type to search applications.
- `Meta` (Windows key) opens the launcher.
- `Alt+Tab` switches windows.
- System settings are available from the launcher.

The HSCL1 default wallpaper is **HSCL1 Midnight**. See [Themes](themes.md) to change the look.
