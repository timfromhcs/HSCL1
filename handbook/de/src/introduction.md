# Einführung

HSCL1 ist eine Linux-Workstation auf Basis von **Ubuntu 26.04 LTS** und **KDE Plasma**. Herausgeber ist HCSMEDIA.
*Mit Liebe gemacht von hcsmedia.*

> **Status: Pre-Alpha.** HSCL1 startet in virtuellen Maschinen (UEFI und BIOS) und öffnet den Kubuntu-Installer.
> Auf echter Hardware wurde nichts getestet. Siehe [Bekannte Einschränkungen](limitations.md).

HSCL1 ist **nicht** Tails, **keine** offizielle Kali-Version und wird weder von Canonical, Offensive Security noch vom Tails-Projekt unterstützt.
