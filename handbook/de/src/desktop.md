# Grundlagen des Desktops

HSCL1 verwendet den HCS-Hybrid-Desktop auf Basis von KDE Plasma 6 mit tastaturgesteuerten Produktivitätsstandards.

- Das schwebende Dock befindet sich zentriert am unteren Bildschirmrand.
- Die schlanke obere Leiste enthält das Anwendungsmenü, das globale Menü, die Uhr und den Systemabschnitt.
- Das Standard-Hintergrundbild heißt **HSCL1 Midnight**. Siehe [Designs](themes.md), um das Aussehen zu ändern.

## Tastenkombinationen

HSCL1 verwendet `Meta` (Super- / Windows-Taste) als primäre Steuerungstaste:

| Tastenkombination | Aktion |
|---|---|
| `Meta` | Start- / Anwendungsmenü öffnen |
| `Meta + Leertaste` | Programmsuche (KRunner) fokussieren |
| `Meta + Eingabetaste` | Terminal (Konsole) öffnen |
| `Ctrl + Alt + T` | Terminal öffnen (Klassischer Fallback) |
| `Meta + E` | Dateimanager (Dolphin) öffnen |
| `Meta + D` | Desktop anzeigen |
| `Meta + Tab` | Fenster wechseln |
| `Meta + K` | Tastenkombinations-Referenz öffnen |
| `Meta + ,` | HSCL1-Kontrollzentrum öffnen |
| `Meta + L` | Bildschirm sperren |
| `Meta + Umschalt + S` | Bereichs-Screenshot aufnehmen |
| `Meta + Links / Rechts` | Fenster links / rechts anheften |
| `Meta + Oben` | Fenster maximieren |
| `Meta + Unten` | Fenster minimieren / wiederherstellen |
| `Meta + 1..9` | Zu virtuellem Desktop 1 bis 9 wechseln |
