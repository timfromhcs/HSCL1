# Grundlagen des Desktops

HSCL1 verwendet den KDE-Plasma-Desktop. Bis das HCS-Hybrid-Desktop-Layout erscheint, gilt das normale Plasma-Verhalten:

- Der Starter befindet sich unten links; tippen Sie, um Anwendungen zu suchen.
- `Meta` (Windows-Taste) öffnet den Starter.
- `Alt+Tab` wechselt zwischen Fenstern.
- Die Systemeinstellungen finden Sie im Starter.

Das Standard-Hintergrundbild von HSCL1 heißt **HSCL1 Midnight**. Siehe [Designs](themes.md), um das Aussehen zu ändern.
