# Sicherheitsstatus

```console
$ hscl security status
$ hscl doctor
```

Diese Befehle zeigen, was auf Ihrem System tatsächlich aktiv ist: Firewall, AppArmor, Secure Boot, Festplattenverschlüsselung und Zustand der APT-Quellen. `hscl doctor` endet mit Exit-Code 3, wenn eine Prüfung fehlschlägt. Berichte verbergen Benutzernamen, Rechnernamen und Netzwerkkennungen.

HSCL1 behauptet nicht, ein System sei „sicher"; es zeigt Belege, damit Sie selbst entscheiden können.
