# Die drei Modi

| Modus | Zweck | Status |
|---|---|---|
| Workstation | alltäglicher Desktop | Pre-Alpha |
| Security Lab | autorisierte Sicherheitstests in isolierten Containern oder VMs | geplant |
| Privacy | datenschutzorientierte Arbeitsabläufe | geplant |

**Security Lab** führt Kali-Werkzeuge in Rootless-Containern aus, niemals durch Hinzufügen von Kali-Paketquellen zum Host. Nutzen Sie es nur auf Systemen, die Sie testen dürfen.

**Privacy** ist nicht Tails. Wenn Ihre Sicherheit von starker Anonymität abhängt, verwenden Sie das echte Tails von tails.net.
