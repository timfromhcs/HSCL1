# Les trois modes

| Mode | Objectif | État |
|---|---|---|
| Workstation | bureau quotidien | pré-alpha |
| Security Lab | tests de sécurité autorisés dans des conteneurs ou VM isolés | prévu |
| Privacy | usages axés sur la confidentialité | prévu |

**Security Lab** exécutera les outils Kali dans des conteneurs sans privilèges, jamais en ajoutant des dépôts Kali à l'hôte. Utilisez-le uniquement sur des systèmes que vous avez le droit de tester.

**Privacy** n'est pas Tails. Si votre sécurité dépend d'un anonymat fort, utilisez la version authentique de Tails sur tails.net.
