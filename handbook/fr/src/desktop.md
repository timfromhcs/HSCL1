# Bases du bureau

HSCL1 utilise le bureau hybride HCS basé sur KDE Plasma 6 avec des paramètres de productivité axés sur le clavier.

- Le dock flottant est centré en bas de l'écran.
- La barre supérieure fine regroupe le lanceur d'applications, le menu global, l'horloge et la boîte à miniatures.
- Le fond d'écran par défaut est **HSCL1 Midnight**. Voir [Thèmes](themes.md) pour modifier l'apparence.

## Raccourcis clavier

HSCL1 utilise `Meta` (touche Super / Windows) comme modificateur principal :

| Raccourci | Action |
|---|---|
| `Meta` | Ouvrir le menu d'applications |
| `Meta + Espace` | Recherche d'applications (KRunner) |
| `Meta + Entrée` | Ouvrir le terminal (Konsole) |
| `Ctrl + Alt + T` | Ouvrir le terminal (raccourci Linux classique) |
| `Meta + E` | Ouvrir le gestionnaire de fichiers (Dolphin) |
| `Meta + D` | Afficher le bureau |
| `Meta + Tab` | Changer de fenêtre |
| `Meta + K` | Ouvrir la référence des raccourcis |
| `Meta + ,` | Ouvrir le centre de contrôle HSCL1 |
| `Meta + L` | Verrouiller l'écran |
| `Meta + Maj + S` | Capture d'écran de région rectangulaire |
| `Meta + Gauche / Droite` | Aligner la fenêtre à gauche / droite |
| `Meta + Haut` | Maximiser la fenêtre |
| `Meta + Bas` | Minimiser / restaurer la fenêtre |
| `Meta + 1..9` | Basculer vers le bureau virtuel 1 à 9 |
