# Bases du bureau

HSCL1 utilise le bureau KDE Plasma. Tant que la disposition HCS Hybrid Desktop n'est pas livrée, le comportement standard de Plasma s'applique :

- Le lanceur se trouve en bas à gauche ; tapez pour rechercher des applications.
- `Meta` (touche Windows) ouvre le lanceur.
- `Alt+Tab` change de fenêtre.
- Les paramètres système sont accessibles depuis le lanceur.

Le fond d'écran par défaut de HSCL1 s'appelle **HSCL1 Midnight**. Voir [Thèmes](themes.md) pour changer l'apparence.
